# AI-assistance disclosure

GSExplorer+ was developed by Gus Salazar with substantial help from an AI model
(Anthropic Claude, used through Claude chat and Claude Code sessions).

| Part | Extent of AI-generated material |
|---|---|
| Application source (`src/gsexplorer/`) | Most of the code was generated by the AI from the author's feature requests, then run, tested and corrected in iterations directed by the author. |
| Tests (`tests/`) | Mostly AI-generated. |
| Packaging (`packaging/`): build script, bundle pruning, license inventory, SBOM, Debian metadata, AppStream MetaInfo, desktop file, man page | Mostly AI-generated. |
| Documentation (`README.md`, this file, `SECURITY.md`, `CONTRIBUTING.md`, `CHANGELOG.md`) | Mostly AI-generated. |
| Icon (`src/gsexplorer/resources/gsexplorer-plus.svg`) | AI-generated. |
| Design decisions, feature scope, acceptance testing on the author's machines | The author. |

The author reviews and is responsible for every release. Report problems at
https://github.com/gstvslzr/GSExplorer/issues.

Some software distribution channels require this information. For example, Flathub requires
submitters to disclose AI-generated material and its extent, and does not accept AI-generated
Flatpak manifests or AI-written submission pull requests
(https://docs.flathub.org/docs/for-app-authors/requirements#generative-ai-policy).
